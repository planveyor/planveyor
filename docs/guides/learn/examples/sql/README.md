# Снимок кода SQL-примера

Здесь лежат процедура, тесты и обвязка исторического SQL sibling, в котором прошла задача из главы [«Сквозной пример: какие товары пора пополнить»](../../sql-example.md). Тесты Planveyor эти файлы тоже не запускают. Живой прогон этих файлов на dev-базе прошёл 28 сентября 2026 года, он описан в главе.

Планы, квитанции, параметры подключения и локальные настройки проекта сюда не перенесены.
