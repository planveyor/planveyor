# Roadmap boundary

Долгосрочная продуктовая карта принадлежит consumer repository. Открытые
обязательства первой версии Planveyor перечислены в [release backlog](release_backlog.md).
Новые shared process changes проходят действующие plans, follow-ups и
process-improvement carriers; сюда не импортируется продуктовый roadmap.
