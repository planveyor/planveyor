# Извещения контракта

Здесь лежат извещения `<change-id>.json` об изменениях общего контракта или механики движка, которые sibling должен принять при обновлении. Формат и правила описаны в [docs_architecture](../playbooks/docs_architecture.md): JSON-объект с однострочным `summary` и массивами строк `contract_changes`, `engine_changes`, `sibling_actions`, `checks`.

`planveyor_contract_upgrade` читает извещения из истории Git этого репозитория в диапазоне от прежнего source commit sibling до выбранного и переносит их в план адаптации sibling. Извещение из коммита, который уже входит в прежний source commit, sibling не увидит. Поэтому каталог начинается пустым: изменения до первого публичного выпуска сюда не переносятся.

Каждое извещение в диапазоне проверяется до создания кандидата; битое извещение останавливает обновление.
