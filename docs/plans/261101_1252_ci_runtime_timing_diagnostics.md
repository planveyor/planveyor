## Executable instrumentation / report contract
- s02 terminal rows сохраняют original label/argv/stdin/stdout/stderr hashes и result object; additive role/subcase, named clock/units и raw start/end/elapsed описаны в draft. Metadata keywords optional для current callers, не required runtime inputs; в primary все четыре scenario roles × second_malformed False/True получают реальные labels; outer correction role не выдаётся за отличающийся prefix-collector --role из actual argv.
